# Specific documents

Rules for particular kinds of output: emails, slide presentations, résumés.

From Butterick’s Practical Typography. Each heading links to the source page.

### [Emails](https://practicaltypography.com/emails.html)

- If you must format emails, stick with common system fonts.
- Don’t rely on font-specific spacing tricks in emails (e.g., aligning with multiple word spaces); simpler is better.
- Alternatively, treat email as a typography-free zone.
- Put contact information in email as text, not an image, so it can be copied and pasted.

### [Presentations](https://practicaltypography.com/presentations.html)

- If presenting in a darkened room, optimize slides for reading in the dark.
- Before adjusting typography, darken your workspace so the only light comes from your screen.
- Start with a black background, “not dark gray, nor a dark gradient—just black.”
- Use a thin sans serif font to minimize photons.
- Start text at 50% gray and brighten until legible; thinner fonts need brighter color. Avoid pure white on black.
- Pick a base size that fits 12–15 lines of text on screen, and use the same size on every slide.
- Use color with restraint, preferring pale shades over bright ones.
- Avoid centered text and huge headlines.
- Don’t set line spacing too tight.
- Avoid boring system fonts.
- In lit rooms, still avoid pure black on pure white; use a light-gray background or dark-gray type.
- Omit list bullets when every point is less than one line.
- You may confine the layout to less than the full screen width, but be consistent across slides.

### [Résumés](https://practicaltypography.com/resumes.html)

- Eliminate typos.
- Spell it “résumé” (preferred); “resumé” is acceptable; “resume” is wrong.
- Never assume a reader gets past the first screen or page; put the most important information first.
- Don’t set body text in a system font (e.g., Calibri).
- Don’t make headings and gray boxes large relative to the body text; headings shouldn’t dominate.
- Make the names of schools and employers immediately visible; don’t bury the where and when.
- Use gentler list bullets.
- Make the résumé skimmable.
- Have one or more people edit your résumé, and insist each propose at least three edits.
