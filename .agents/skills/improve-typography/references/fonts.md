# Fonts

Choosing, licensing, loading, and identifying fonts; the system-font A/B/C/F lists; recommended free fonts; alternatives to common defaults; fonts to avoid.

From Butterick’s Practical Typography. Each heading links to the source page.

### [Font recommendations](https://practicaltypography.com/font-recommendations.html)

- Learn type composition and text formatting before fiddling with fonts; changing fonts is no substitute for the fundamentals.
- For the fastest, easiest upgrade to your typography, use a professional font: “nothing beats a professional font.”
- Exception: system fonts are acceptable, even the best option, for emails and draft documents.
- Writers who care about typography should treat professional fonts as essential tools.

### [Font basics](https://practicaltypography.com/font-basics.html)

- Prefer professional fonts; the best ones beat any system font or free font.
- Budget for fonts: a top-quality professional family runs under $200, or roughly $20–50 per style.
- Narrow your font choice by practical requirements, cost, and personal taste.
- Imitate fonts you admire; nearly all can be licensed (see identifying fonts).
- For body text, get at least the core styles: roman, italic, bold, bold italic, and roman small caps.
- Don’t judge a font’s quality or look by a historical name in its title (Garamond, Baskerville, Caslon); same-named fonts can differ greatly (Stempel Garamond vs. ITC Garamond).
- On the web, load fonts with `@font-face` and apply them with `font-family`.
- Respect font licenses: buy as many licenses as you need and don’t share a single-user license across an organization.
- It’s fine to use “font” to mean both the family and a specific style.

### [System fonts](https://practicaltypography.com/system-fonts.html)

- Avoid system fonts if you can; choose wisely if you can’t. Professional writers should use professional fonts.
- If your project needs novelty, avoid overexposed system fonts (e.g., don’t set “A Design Firm Unlike Any Other” in Helvetica).
- If limited to system fonts: for screen (presentations, websites) and draft documents, the A and B lists are fine; avoid the C list if you can; never use the F list (“F list, kapu”).
- A list (generally tolerable; ★ = plausible for body text): Athelas★, Avenir★, Bell MT★, Book Antiqua★, Californian FB★, Calisto MT★, Century Schoolbook★, Charter★, Franklin Gothic★, Garamond★, Gill Sans★, Gill Sans MT★, Goudy Old Style★, Helvetica★, Helvetica Neue★, Hoefler Text★, Iowan Old Style★, Optima★, Palatino★, Seravek★, Sitka★.
- B list (OK in limited doses): Agency FB, Big Caslon, Bodoni MT, ITC Bodoni 72, Calibri★, Candara, Centaur, Constantia, Corbel, Futura★, Geneva, Gloucester MT Extra Cond., High Tower Text★, Modern No. 20, Perpetua★, Rockwell, Segoe UI★, Tw Cen MT★.
- C list (questionable): Andale Mono, Baskerville★, Berlin Sans FB, Bernard MT Condensed, Cambria★, Castellar, Century Gothic, Cochin, Consolas, Cooper Black, Courier, Courier New, Didot, Elephant, Engravers MT, Eras ITC, Felix Titling, Georgia, Haettenschweiler, Impact, Lucida (all styles), Maiandra GD, Menlo, Niagara Solid & Engraved, Onyx, Plantagenet Cherokee, Skia, Times New Roman★.
- F list (“fatal to your credibility”): Algerian, American Typewriter, Apple Casual, Apple Chancery, Arial (all styles), Bauhaus 93, Blackadder, ITC Bradley Hand, ITC Britannic Bold, Broadway, Brush Script MT, Bookman Old Style, Century, Chalkboard, Chalkduster, Chiller, Colonna MT, Comic Sans MS, Copperplate, Curlz MT, Edwardian Script ITC, Footlight MT Light, Forte, Freestyle Script, French Script MT, Gabriola, Gigi, Goudy Stout, Harlow Solid Italic, Harrington, Herculanum, Imprint MT Shadow, Informal Roman, Jokerman, Juice ITC, Kristen ITC, Kunstler Script, Luminari, Magneto, Marker Felt, Matura MT Script Capitals, Mistral, Monaco, Monotype Corsiva, Noteworthy, OCR A Extended, Old English Text MT, Palace Script MT, Papyrus, Parchment, Playbill, Phosphate, Poor Richard, Pristina, Rage Italic, Ravie, Savoye, Script MT Bold, Segoe Print, Segoe Script, SignPainter, Snap ITC, Snell Round, Stencil, Showcard Gothic, Tahoma, Tempus Sans ITC, Trattatello, Trebuchet MS, Verdana, Viner Hand ITC, Vivaldi, Vladimir Script, Wide Latin, Zapfino, “and all others.”
- Use non-★ fonts only for special purposes, not body text.
- On the web, screen-optimized webfonts and high-res screens are eroding system fonts’ advantage; using professional fonts just takes a little more legwork.
- Don’t use Arial: “you cannot create good typography with Arial”; it’s “the sans serif of last resort.” Use Avenir, Franklin Gothic, Gill Sans, a Helvetica/Arial alternative, or something completely different.

### [Free fonts](https://practicaltypography.com/free-fonts.html)

- Use free (open-license, e.g. OFL) fonts when a project requires them, such as shipping fonts with open-source software, but choose wisely: “most free fonts are garbage.”
- Recommended free fonts: Source Code (mono) and Source Serif (Adobe), Cooper Hewitt (sans), IBM Plex (sans, serif, mono), Charter.
- Don’t waste time panning through other free fonts; it’s more efficient to buy a professional font.
- Don’t confuse system fonts with free fonts: system fonts carry proprietary licenses that restrict use.

### [Charter](https://practicaltypography.com/charter.html)

- If your project needs a font without licensing restrictions, consider Charter, “easily one of the best free fonts available”; it holds up well on screen.
- Use Charter subject to its original Bitstream license, keeping the notice intact.
- Prefer this Charter over Charis unless you need Charis’s larger character set; Charis has “questionable design modifications.”

### [Helvetica & Arial alternatives](https://practicaltypography.com/helvetica-and-arial-alternatives.html)

- Prefer better options than Helvetica today; it’s bland, overused, and inapt for most projects.
- Alternatives: Neue Haas Grotesk (for Helvetica diehards; a revival of the original); for neutral but not dull, Concourse, Hermes Maia, or Atlas.
- Never use Arial: “you cannot create good typography with Arial.”

### [Times New Roman alternatives](https://practicaltypography.com/times-new-roman-alternatives.html)

- If you have a choice about using Times New Roman, “please stop. Use something else”; it “connotes apathy.” See font recommendations.
- For diehard Times New Roman fans, alternatives with its flavor but fewer shortcomings: Plantin, Equity.

### [Courier alternatives](https://practicaltypography.com/courier-alternatives.html)

- Avoid monospaced fonts generally; when you must use one, don’t use Courier New (“spindly, lumpy, and just plain ugly”).
- Alternatives: Triplicate (genuine italics and small caps, optimized for body text), Pitch, Input, Fira Mono (a free font recommended “without reservation”).

### [Palatino alternatives](https://practicaltypography.com/palatino-alternatives.html)

- Avoid the Palatino system font, a harsh rendering of Zapf’s design; its novelty is dimmed by overuse.
- Alternatives: Palatino Nova (Zapf’s own restoration), Iowan Old Style, Verdigris, Valkyrie.
- The same alternatives apply to Book Antiqua, a Palatino clone.

### [Baskerville alternatives](https://practicaltypography.com/baskerville-alternatives.html)

- Avoid the Baskerville system font (“brittle and excessively quaint”).
- Alternatives: Baskerville 10 (best recreation of Baskerville’s own fonts), Ingeborg, Kingfisher.

### [Century Schoolbook alternatives](https://practicaltypography.com/century-schoolbook-alternatives.html)

- Century Schoolbook is tolerable, but its letterforms are loose and broad; choose a better Scotch-style face.
- Alternatives: Miller, Harriet, Ingeborg, Century Supra.

### [Georgia alternatives](https://practicaltypography.com/georgia-alternatives.html)

- Georgia’s 1990s screen compromises are obsolete.
- Alternatives: Miller (same Scotch influence, more subtlety), Harriet, Chronicle, Century Supra.

### [Verdana alternatives](https://practicaltypography.com/verdana-alternatives.html)

- Don’t use Verdana for anything other than “the websites of the 1990s.”
- Alternatives: Alright Sans (humanist), Sweet Sans, Breuer, Concourse, Hermes Maia.

### [Gill Sans alternatives](https://practicaltypography.com/gill-sans-alternatives.html)

- Gill Sans is acceptable but overexposed; you can do better.
- Alternatives: Ideal Sans, Brandon Text, Verlag, Concourse.

### [Cambria alternatives](https://practicaltypography.com/cambria-alternatives.html)

- Cambria’s excess consistency makes it monotonous, though it’s fine on screen.
- Alternatives: Guardian Egyptian, Elena, Skolar; free options Charter and Source Serif.

### [Calibri alternatives](https://practicaltypography.com/calibri-alternatives.html)

- Calibri’s rounded corners make body text look soft; don’t settle for it.
- Alternatives: Concourse, Guardian Sans, Seravek (similarly narrow), Fort (wider, more open).

### [Minion alternatives](https://practicaltypography.com/minion-alternatives.html)

- “You need to stop using Minion”; it’s a default, “the absence of a font choice.” Don’t rely on defaults.
- Alternatives: Equity, Valkyrie, Century Supra, Lyon.

### [Bad fonts](https://practicaltypography.com/bad-fonts.html)

- Don’t use Comic Sans, though it’s at least “honest about what it is.”
- Skip Papyrus; it’s neither historic nor hand-drawn.
- Avoid Bookman (“the corduroy suit”) and Bodoni (“annoying to read after three words”) as skunked fonts.
- Avoid Copperplate; as a “classy” signal on signage and menus, “it’s not working.”
- Avoid early digital-age script fonts like those bundled with Microsoft Office (e.g., Brush Script); modern OpenType scripts are far better.

### [Identifying fonts](https://practicaltypography.com/identifying-fonts.html)

- Imitate typography you like, including font choices; learn to identify fonts.
- On websites, inspect the CSS `font-family` property, or use the WhatFont browser extension.
- For images of type, try WhatTheFont with a good photo.
- Try Identifont.
- Ask a typographer, e.g., tweet a photo to @Font_ID or @TypeID.
- Study distinctive key characters (A, E, G, M, Q, R, S, a, e, f, g, r, s, t, and the ampersand) rather than punctuation.
